# Monitoring

Sample Visualization for Public Monitoring using Petition/Civil Complaint Data between 2021 and 2023.

2021~2023년 민원 데이터를 활용한 공공 모니터링 시각화 예시입니다.

## 시각화 바로가기

아래 링크를 클릭하면 GitHub 파일 화면이 아닌 **대화형 지도**가 열립니다.

### 이용 안내

- 시각화 구분은 저장소의 파일 식별자(`FLAG`, `HOLE`, `MTRL`, `PARK_ALL`)를 기준으로 표시했습니다.
- **AI 버전**은 파일명에 `_AI`가 붙은 별도 시각화입니다. 해석 시 해당 지도에 표시된 정보를 확인해 주세요.
- 지도 파일은 각각 약 **78~83 MB**로, 네트워크 환경에 따라 처음 열 때 시간이 걸릴 수 있습니다.
- `PARK_ALL`의 2023년 AI 버전은 현재 저장소에 포함되어 있지 않습니다.
